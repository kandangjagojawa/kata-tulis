# Membandingkan Tata Tulis Aksara Jawa

Repositori ini berisi kajian dan perbandingan berbagai paugeran (pedoman) penulisan Aksara Jawa, dari paugeran modern hingga tradisional dan Kawi. Tujuannya adalah untuk memahami perbedaan cara penulisan, transliterasi, dan pemaknaan bunyi yang sama dalam sistem yang berbeda.

## 1. Ruang Lingkup Perbandingan

Perbandingan dibagi menjadi dua kelompok besar:

### Tata Tulis Baru
Sistem penulisan yang digunakan untuk Bahasa Jawa Baru (Ngoko-Krama modern).

### Tata Tulis Lama
Sistem penulisan yang mempertahankan bentuk dan aturan yang lebih klasik, terutama untuk keperluan sastra, arsip, dan bahasa Jawa Kuno.

## 2. Enam Sistem Tata Tulis yang Dibandingkan

1.  **Paugeran KBJ (Kongres Bahasa Jawa)**
    Paugeran resmi modern hasil Kongres Bahasa Jawa. Bersifat paling simplifikasi, menghilangkan banyak aksara murda dan aksara rekan yang dianggap tidak perlu untuk Jawa modern. Fokus pada kepraktisan belajar.

2.  **Paugeran Sriwedari (1926)**
    Paugeran klasik hasil pertemuan di Sriwedari, Surakarta. Menjadi dasar pengajaran Aksara Jawa di sekolah-sekolah selama puluhan tahun. Lebih lengkap dari KBJ tetapi sudah mulai disederhanakan dari tradisi lama.

3.  **KAJ Simplified**
    Versi sederhana dari Kitab Aksara Jawa (KAJ). Mengupayakan keseimbangan antara kemudahan baca modern dan kelengkapan aksara tradisional.

4.  **KAJ Tradisional**
    Versi lengkap Kitab Aksara Jawa. Mempertahankan aturan pasangan, konsonan ganda murdhanya, dan penggunaan aksara mahaprana (ba, ca, da, ga, ja yang berdot / mahaprana) secara konsisten. Menjadi jembatan menuju Mardi Kawi.

5.  **Cara Kawi (Mardi Kawi)**
    Tata tulis untuk menulis Bahasa Jawa Kuno (Kawi) dan Sanskerta. Mempertahankan seluruh aksara termasuk: 
    - Aksara murda dan mahaprana (ꦑ, ꦑ꦳, ꦓ, ꦨ, dll)
    - Vokal panjang: aa, ii, uu, ee, oo (ꦴ, ꦷ, ꦹ, ꦺꦴ)
    - Vokal khusus Sanskerta: ꦉ (re pepet), ꦊ (le), ꦋ (lee panjang), ꦅ (Ix), ꦍ/ꦎ untuk diftong ai/au
    - Pasangan dan sandhangan yang lebih kompleks

6.  **Aksara Jawa Praktis & Ringkasan Transliterasi**
    Versi ringkas untuk penggunaan sehari-hari dan rekap perbandingan hasil transliterasi dari kelima paugeran di atas.

## 3. Sistem Transliterasi Pendukung

Setiap hasil Aksara Jawa dilengkapi dengan tiga sistem alih aksara ilmiah:

-   **JGST (Javanese General System of Transliteration)**
    Sistem transliterasi baku untuk Aksara Jawa ke Latin dengan diakritik. Contoh: ba / ḅa, ca / c̣a, da / ḍa, ṅa / ŋ, ña, śa / ṣa, ḥ, ā, ī, ū, ě, é, ŕě, lě.

-   **IPA (International Phonetic Alphabet)**
    Pelafalan fonetis yang presisi. Contoh: [ba] vs [bʱa], [tʃa] vs [tʃʰa], [ɖa], [ɳa], [ŋ], [ɲ], [e] / [ə] / [ɛ], [o] / [ɔ].

-   **PUJL (Pedoman Umum Ejaan Jawa Latin)**
    Ejaan Latin Jawa yang disederhanakan dan umum dipakai masyarakat. Contoh: ba, ca, da, dha, nya, sa, é, e, le, re.

## 4. Panduan Penulisan Huruf Latin

Kaidah input Latin untuk menghasilkan Aksara Jawa yang benar meliputi:

**Vokal dan Diftong:**
`a / A` = ꦄ / ꦲ, `aa` = ꦴ (a panjang), `ai` = ꦍ / ꦻ, `au` = ꦎꦴ / ꦻꦴ, `e / é / è` = ꦌ / ꦺ / ꦼ, `i` = ꦆ / ꦶ, `ii` = ꦇ / ꦷ, `Ix` = ꦅ (vokal khusus Kawi), `le / lě` = ꦊ, `lee` = ꦋ, `re / rě` = ꦉ / ꦽ, `ree` = ꦉꦴ, `u` = ꦈ / ꦸ, `uu` = ꦈꦴ / ꦹ

**Konsonan Dasar dan Mahaprana:**
`b / B` = ꦧ / ꦨ, `bh` = ꦨ, `c / C` = ꦕ / ꦖ, `ch` = ꦖ, `d` = ꦢ, `dh / DH` = ꦝ / ꦞ / ꦣ, `g / G` = ꦒ / ꦓ, `j / J` = ꦗ / ꦙ, `jh` = ꦙ, `k / K` = ꦏ / ꦑ, `p / P` = ꦥ / ꦦ, `ph` = ꦦ, `t / T` = ꦠ / ꦡ, `th / TH` = ꦛ / ꦜ, `l` = ꦭ, `m` = ꦩ, `n / N` = ꦤ / ꦟ, `ng` = ꦔ / ꦁ, `ny` = ꦚ / ꦘ, `r` = ꦫ / ꦬ / ꦂ, `s / S` = ꦱ / ꦯ / ꦰ, `sh` = ꦰ, `sy` = ꦯ, `w` = ꦮ, `y` = ꦪ / ꦾ, `h` = ꦲ / ꦃ

**Aksara Rekan (untuk serapan Arab/Persia/Eropa):**
`f` = ꦥ꦳, `v` = ꦮ꦳, `z` = ꦗ꦳, `kh` = ꦏ꦳, `gh` = ꦒ꦳, `dz` = ꦢ꦳, `dl` = ꦭ꦳, `q` = ꦐ, `hh` = ꦲ꦳, `xng` = ꦔ꦳, `xsy` = ꦯ꦳, `shh` = ꦰ꦳, `zh` = ꦣ꦳, `ts` = ꦱ꦳, dll. Ditandai dengan cecak telu `꦳` (U+A9B3).

**Sandhangan dan Tanda Baca:**
`Pangkon` = ꧀ (U+A9C0), `Panyangga` = ꦀ (U+A980) untuk -m / -ng, `Tolong` = ꦵ (U+A9B5) untuk -o, Angka Jawa ꧐-꧙, Pada: `꧈ ꧉ ꧇ ꧋ ꧌ ꧍ ꧏ ꧅ ꧄ ꧃ ꧆`, dll.

## 5. Aturan Khusus: r-Mati di Tengah Kata

Khusus untuk modul KAJ Tradisional & Cara Kawi, terdapat aturan konsonan ganda setelah r-mati (layar / cakra keret). Secara baku, `karna` ditulis `ꦏꦂꦟ꧀ꦤ` (Ra + konsonan ganda murdhanya).

Untuk mengendalikan pembentukan ini, digunakan simbol pemicu:

| Pendekatan | Simbol | Contoh | Hasil Tradisional | Keterangan |
| :--- | :--- | :--- | :--- | :--- |
| **Baku** | (tanpa simbol) | `karna` | ꦏꦂꦟ꧀ꦤ | Aturan baku: Layar + Konsonan Ganda Murdhanya |
| **A** | `~` atau `!` | `kar~na` | ꦏꦂꦤ | Batal ganda, menjadi Aksara Tunggal Biasa (Dantya) |
| **B** | `[C1\|C2]` | `kar[n\|N]a` | ꦏꦂꦤ꧀ꦟ | Menentukan Pasangan Kustom Eksplisit (C1 + Pasangan C2) |
| **C** | `#` atau `^` | `kar#na` | ꦏꦂꦟ | Batal ganda, menjadi Aksara Tunggal Mahaprana (Murda) |

## 6. Fitur Linguistik Jawa

### A. Tembung Dwipurwa
Pembentukan kata dwipurwa (pengulangan suku kata pertama) dalam paugeran Sriwedari. Contoh: dari tembung lingga `tuku` menjadi `tetuku`. Alat ini membantu membentuk dwipurwa secara otomatis sesuai kaidah Sriwedari dan menampilkan pratinjau Aksara Jawanya.

### B. Paramasastra - Pemberian Imbuhan
Pembentukan kata berimbuhan lengkap yang terdiri dari:

**Ater-ater (Awalan):**
`N-` (anuswara otomatis m/n/ny/ng), `m-, n-, ny-, ng-, pa-, pating paN-, kuma-, kami-, kapi-, pi-, ma-, sa-, in-, dak-, tak-, kok-, ko-, di-, ka-, ke-`

**Tembung Lingga (Kata Dasar):**
Kata dasar yang akan diberi imbuhan.

**Panambang (Akhiran):**
`-i / -ni / -nni, -ake / -aké, -aken, -en / -nen, -ana / -nnana, -ne / -é, -ku, -mu, -an / -nan, -e / -é, -a / -ya / -wa, -na / -kna, -ipun / -nipun`

Contoh proses: `N- + tulis + -an` → `nulisan`, yang kemudian dapat ditransliterasikan ke dalam Aksara Jawa dengan paugeran yang dipilih.

## 7. Pengurutan dan Klasifikasi

Untuk keperluan pembelajaran, daftar aksara dapat diurutkan berdasarkan:
1.  Urutan Alfabet Latin
2.  Urutan Hanacaraka (ha-na-ca-ra-ka...)
3.  Urutan Warga Aksara (berdasarkan tempat artikulasi: Kanthya, Talawya, Murdhanya, Dantya, Osthya)
4.  Urutan Unicode (U+A980 - U+A9DF)
5.  Urutan Tata Tulis Baru
